# TypeScript Programming Problem Solving
**Batch:** 18

## Prerequisites

Install the following software:

- Node.js (Latest LTS)
- Visual Studio Code

Verify installation:

```bash
node -v
npm -v
```

## Clone Repository

```bash
git clone <your-github-repository-url>
cd <repository-name>
```

## Install Dependencies

```bash
npm install
```

Install TypeScript and ts-node:

```bash
npm install -D typescript ts-node @types/node
```

## Initialize TypeScript

```bash
npx tsc --init
```

## Run Any Program

Example:

```bash
npx ts-node src/01-difference-max.ts
```
